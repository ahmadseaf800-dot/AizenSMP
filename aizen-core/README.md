# AizenCore

AizenSMP custom plugin built from scratch in Java for Purpur 1.21.11.

Current source systems:
- Economy: /balance, /pay
- Kill-streak bounty: starts at 5 kills and grows by $1000 per extra kill
- Bounty leaderboard: /bounty

More AizenSMP systems will be implemented in this custom codebase instead of installing unrelated gameplay plugins.
