# AizenSMP - Spawner System

## Features
- Spawner GUI.
- Buy/sell/configurable spawner prices.
- Configurable mobs.
- Spawner placement and break protection.
- Ownership validation.
- Optional Silk Touch/custom pickup rules.
- Admin give/remove controls.
- Persistent spawner data.
- Anti-duplication validation.
- Integration with Shop, Economy, Crates and Keys.

## Safety
Spawner transactions must validate inventory space, balance, ownership and the target block before changing anything.
