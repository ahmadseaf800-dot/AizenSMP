# AizenSMP Project

## Goal
Build a custom SMP server with systems developed specifically for AizenSMP.

## Development order
1. Core system
2. Player data/statistics
3. Spawn and protection
4. Economy
5. Shop
6. RTP / homes
7. PvP systems
8. Custom events
9. Leaderboards
10. Administration and anti-abuse protections

## Rule
Every system should be tested before adding the next major system.
